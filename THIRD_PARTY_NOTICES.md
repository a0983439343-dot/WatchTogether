# Third-party notices — WatchTogether 2.0

The 2.0 UI uses the following open-source packages/patterns, pinned to the versions researched on 2026-09-27.

- Tabler Core 1.6.0 — MIT
  Source: https://github.com/tabler/tabler
  Used for the shared visual system / admin dashboard base.
- Chart.js 4.5.1 — MIT
  Source: https://github.com/chartjs/Chart.js
  Used for Admin analytics charts.
- SortableJS 1.15.7 — MIT
  Source: https://github.com/SortableJS/Sortable
  Used for queue drag/reorder support.

Additional watch-party projects were reviewed for implementation patterns (synchronization, rooms, chat, roles and moderation), but their code is not copied where the architecture or licensing is not directly compatible with this project.
