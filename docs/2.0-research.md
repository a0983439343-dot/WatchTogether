# WatchTogether 2.0 research log

## Rule
For each major 2.0 feature, research an existing implementation first. Prefer a maintained, directly reusable component/library with a clear license. Only write a custom implementation when the existing project cannot be safely/cleanly integrated with the current Firebase/static-site architecture.

## Researched and adopted
| Area | Reference | Result |
|---|---|---|
| Admin dashboard/layout | Tabler 1.6.0 | Adopted as the visual foundation. MIT. |
| Charts | Chart.js 4.5.1 | Adopted for Admin analytics. MIT. |
| Queue drag/drop | SortableJS 1.15.7 | Adopted for queue reordering. MIT. |
| Watch-party sync/chat/roles patterns | AlmazHecker/watch2gether | Reviewed; WebRTC architecture is different from this Firebase architecture, so patterns were referenced rather than copied wholesale. |
| Watch-party rooms/social/moderation/gamification | kevinreber/watch-party | Reviewed as a feature reference; current stack is React/Convex/Clerk, so direct code reuse is not appropriate. |
| Watch-party sync/chat/mobile | KAWDHITHA-NIRMAL/Movie-Web | Reviewed for interaction patterns; Firebase-based and therefore useful as a behavioral reference, but not copied without source-level compatibility checks. |
| Watch-party roles | Pari-t23/watch-party-app and Srasti527/yt-watch-party | Reviewed for Host/Moderator/Participant permission patterns. |

## 2.0 implementation order
1. UI shell and routing/navigation without removing the existing functional DOM.
2. Account/room restrictions and permission-aware UI.
3. Persistent personal rooms and public room discovery/data model.
4. Chat/queue/player improvements.
5. AI Core + tools/function calling.
6. Admin 2.0 operational controls.
7. Analytics, audit, security, maintenance and feature flags.
8. Full i18n and responsive QA.

## Safety for reuse
- No proprietary/closed-source UI will be copied into this project.
- Licenses will be recorded before adopting third-party code.
- Existing WatchTogether business logic is preserved unless a replacement is verified to be behaviorally equivalent.
